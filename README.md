# Agent 模式（Cuckoo Code 插件）

让 AI 更主动地使用子代理——注入「委派准则」提示词 + 侧边栏总开关。

## 安装

在 Cuckoo Code 的「插件市场」搜索 **Agent 模式**，一键安装。

## 功能

- **委派准则注入**：AI 会更主动地把任务委派给子代理（大范围搜索、独立子任务、上下文保护）
- **侧边栏开关**：一键启用/禁用，状态存 `plugins-config.json`

## 效果

开启后，AI 遇到这些场景会**优先委派**而不是自己扛：
- 大范围搜索/探索（需要扫很多文件才能定位）
- 独立子任务（与主线弱耦合、可并行推进）
- 上下文保护（会产出大量中间信息、但只需摘要）
- 有专用子代理时（如 arch-guard / code-reviewer）
